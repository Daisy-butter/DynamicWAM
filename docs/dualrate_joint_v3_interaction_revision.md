# DualRate V3：可监督未来、交互与数据身份修订

日期：2026-10-24。此修订依据用户对数据缺口的进一步要求；不以未知标签冒充已经实现的预测能力。

## 紧凑未来改为 12 个有效 token

当前正式候选的实体顺序是 `tracked_dynamic_target / left_gripper / right_gripper`，每类预测 `+0.1 / +0.2 / +0.4 / +0.8 s`，共 12 个 134 维 token。原设计的四实体、16 token 是起始预算；本次删除没有轨迹监督的第二关联实体／support 槽位，同时保留完整慢路的场景和未来视频参考。

`tracked_dynamic_target` 指原始记录的动态对象，并不总是被机械臂拿起的物体。例如 `place_bread_basket` 记录动态篮子，`place_container_plate` 记录盘子，`place_object_scale` 记录秤。这些已有真实轨迹不会被当成 support 丢弃。新 episode 清单保存对应专家轨迹文件中的 `target_actor_name`、来源文件 SHA256 和 `interception/target_pose_wxyz` 字段身份；它们仅用于数据审计，不进入模型条件。

六类实际 HDF5 检查覆盖了篮子、柜体、支架等任务。现有文件保存动态目标、双夹爪、相机位姿和目标接触；没有第二实体的逐帧位姿、深度或分割，pointcloud 为空。scene_info 只有模型、手臂及纹理标识；专家 pkl 有关节路径和动态目标轨迹／随机状态，没有逐帧完整场景状态。篮子会被抬起、柜门会运动，不能把初始位姿当作全过程真值。将来补充第二实体必须用经过逐时刻目标／夹爪／相机／时钟比对验收的精确重放或重新采集；当前不混入近似重放标签。

## 视觉目标和遮挡的边界

128 维视觉目标明确为真实未来图像中、真实实体位置投影附近的局部图像上下文。它可能包含遮挡者，这是该局部区域实际可见的图像内容；不称为无遮挡物体特征，也没有新增“真实遮挡预测头”。只有真实帧配对、投影／图像区域有效时才计算这项视觉 loss。位置、相对夹爪位置来自真实几何记录，出视野不会使已知几何标签变假。

目标有视觉128、xyz3、相对相关夹爪3及双手接触监督；夹爪有视觉128和xyz3，未定义的相对字段及缺失接触字段不参加 loss。静态能力掩码在训推两端一致；完全没有任何训练字段的 token 不进入 A/Z 自注意力，部分 token 中从未训练的字段使用恒定零 padding，不让随机伪状态影响动作。逐样本未来标签／可见性掩码仍只作用于监督，不提供给模型；本来具备训练能力但该样本缺失真值的字段保持纯噪声。

## 三条交互规则的落实

1. A/Z 使用绝对物理目标时刻读取慢路未来。动作行的值是在区间结束时达到的 drive target，故网络的动作目标时间使用 `action_intervals[..., 1]`；队列仍以区间起点标识动作行。软参考保留 source 到目标时刻的相关计划历史，恰好在边界开始的下一行不进入该边界的参考。
2. 慢路门控同时接收当前观测 cross-attention 响应、时间／噪声条件和实际执行动作与旧参考的偏差，可学习根据最新证据降低旧参考权重。初始化仍为 0.1；这表示结构具备该能力，不等于尚未训练的门控已经识别正确失配。
3. 慢路动作仅为软参考，实际已执行历史与硬前缀按同一物理区间比较。干净专家后缀不进入常规联合生成条件；明确的动作条件未来辅助模式除外。快路每次积分硬钳制前缀，原始队列值由执行器保留，不平均两路动作。

## 数据与阶段身份

V3 创建新 manifest 与带目标身份来源的 episodes.json，引用原 V2 的不可变 raw/flow、样本行和完整 T5 缓存，不重写旧数据。新 manifest 绑定 episode 元数据、text index、prompt manifest 的 SHA256，loader 即使关闭行索引全量 hashing 也验证这些元数据。

模型只保留旧 token 索引 `[0:4, 8:16]`。134 维统计是按字段共享的训练集统计，原缺失 support 从未参加拟合，因此不重新拟合或混入验证集。数据行、真实时间和专家动作保持原样。短预热冻结慢路时跳过无梯度用途的原生监督前向，仍重新生成真实 source-only M；后续联合阶段恢复完整原生监督和快路到慢路梯度。

CPU／接口检查不等同于八卡训练、连续 DOMINO 或实时性能验收。正式启动以本轮独立 GPU、严格重载和部署收据为准。
