# DualRate V3 数据与未来表示修订

2026-10-24。用户要求对 support 位姿与真实遮挡缺失问题作出判断并实际修正。本修订覆盖原设计稿的四实体 Z 定义；完整慢路、快路联合 A/Z、参考与承诺分离等主结构保留。

## 证据与裁决

现有真实 HDF5 含动态 tracked target pose、双手 EE pose、目标与双手接触、RGB、相机内外参及 sim time；pointcloud 为空，缺少第二相关物体的逐帧 pose、深度、实例分割和真实可见性。scene_info 只含实例名称、手臂、纹理等；expert trajectory 包含关节路径和 tracked target 动态运动参数，没有全部 actor 的逐帧状态。篮子会被抬起、柜门 articulation 会运动，初始 pose 不能充当全程标签。drive-target 也不能冒充实际关节状态进行精确遮挡重渲染。仅凭 seed 的近似重放不能标为原视频真值。

当前实体角色为 tracked_dynamic_target、left_gripper、right_gripper，各四个未来时刻（.1/.2/.4/.8 秒），共12 token。删除旧第二相关物体/support槽位，而非留无监督噪声参与动作生成。tracked target 的实际含义由 episode 中动态 actor 身份决定；例如一些任务跟踪篮子、盘子或秤，不能笼统称作被抓物。完整慢路场景表示和当前多视角观察仍提供其余实体的视觉信息。

## 视觉与几何的语义

128维视觉目标改为真实未来图像中目标投影点附近的局部上下文，由冻结 ResNet 提取。若被遮挡，区域包含真实遮挡物也是这个定义下的有效图像内容。这里不监督或宣称无遮挡对象特征、不训练额外遮挡头、不用未知可见性当作可见。有效性仅来自有限投影、相机范围、真实帧及裁剪条件。几何 xyz、目标相对相关夹爪的位置和接触仍使用实际轨迹记录，视觉无效不会无故删除可靠几何监督。

这一选择改变了原稿的对象ROI/遮挡掩码语义，保留了快路预测交互相关几何和短期图像变化的主要目的。可见性检测和第二相关实体预测留待具有明确 actor 绑定、逐帧状态、深度/分割或经验证重放的数据版本；当前结果不得宣传这些尚未训练的能力。

## 数据版本与验收

V2原始图像、轨迹、索引、划分和完整T5缓存保持不变。V3独立清单绑定这些原文件并按原槽位0:4、8:16投影标签、统计和字段能力，所有训练/部署请求严格使用12槽位同一实体顺序。原support槽位此前全无监督，移除它不需要重拟合保留字段的训练统计。新增 episode/prompt/text-index 元数据哈希防止身份漂移。

必须验证实际 train/validation 行12槽位形状、真实有效字段计数、没有support噪声路径、训练与在线实体顺序/时间一致，以及完整GPU训练/部署。原V2四步权重和早期V3未冻结结果不能作为本版正式初始化。实际八卡验收和正式启动状态由独立运行收据决定，本文不是完成声明。
