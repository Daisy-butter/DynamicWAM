# 时序反馈训练数据与时基审计

这些文件保存2026-10-06的只读CPU审计证据，不是闭环准确率或GPU训练验收。

- `dataset_audit_singlelag_v1.json`：真实训练/验证各256 pair，覆盖35任务与全部age0..15；记录逐pair索引、时钟字段SHA、原视频/sidecar位置与文件stat、官方full/normalizer身份、源码SHA。9450/1050 episode隔离，历史帧前3 raw frame。含用替代采样器执行的真实训练辅助函数测试：精度、history介入不改变teacher target、age0/arm/tail梯度与误差掩码、7rank序列分片。没有构建真实教师网络，CUDA未初始化。
- `time_coverage_singlelag_v1.json`：扫描上份审计选中478个episode的完整clock，并读取既有共同29任务的完整评测query日志。训练前3帧的物理间隔最大0.180000009秒；旧反馈四命令间隔96.04%大于其四倍。在线age4/8/12计划秒龄分别97.49%/97.73%/99.55%超出训练抽样最大值。
- `dataset_audit_multilag_v2.json`：相同512个pair、九种真实lag全部覆盖；CPU合约全部通过，CUDA未初始化。训练历史dt中位数0.360秒、p95=1.877秒、最大2.160秒；验证为0.420/1.869/2.160秒。训练9个lag1候选、验证10个lag1及1个lag2候选处于同sim tick，已显式排除；没有以伪时间替代。

旧日志只记录四命令query时钟。四命令和超过4倍训练最大值，能证明其中至少一条命令超过训练最大值；不能通过分位数除4恢复单命令分位数。

这份证据触发v2修正：从真实raw frame lag `{1,2,3,6,9,12,18,24,36}`中按pair身份/partition seed的确定性哈希选择过去图像，读取真实dt；有clock但dt=0的同sim tick候选明确排除，所有候选都无正dt时使用invalid history。缺时间戳、负值或非有限值仍失败。计划物理秒龄只保留遥测，避免模型从几乎固定的训练时间映射向在线长时长无约束外推。

多lag仅扩大视觉历史间隔的训练支撑；不能据此宣称解决了执行生成计划后的状态分布偏移或改善成功率。新版审计、固定target探针及闭环对照需各自保留独立结果。
