# V10 关节跟踪偏差：真实物理重放诊断，2026-11-02

结论：两场景的大跟踪偏差主要由碰撞阻挡造成，但当前不能当作正常接触而放行训练。现版逐关节 C2 可行域投影存在明确的路径改写风险，已在相同 Full 动作重放中诱发显著跟踪误差。它不是 C2 连续性本身必然带来的问题，也不是靠增加快路残差幅度就应该解决的问题。

## 当前策略轨迹与碰撞对照

同 seed=100000、初始场景、32 个真实动作区间（每区间45个实际物理步，约5.76秒）；不运行模型、不改变物理钟步长。正常重放与原 deployment03 的288个 q/qdot/command 样本逐数值完全一致。禁碰撞为全新独立诊断场景，绝不用于正式训练或计分；驱动参数仍 stiffness=1000、damping=200。

| 场景 | 当前正常碰撞最大误差 | 同动作取消机器人碰撞 | 旧 Full 原动作/原线性执行器 |

| adjust_bottle | 0.600926 rad | 0.008549 rad | 0.021399 rad |
| place_object_basket | 0.381228 rad | 0.009032 rad | 0.007313 rad |

两例当前轨迹误差峰值均有左臂 fl_link5 与 fl_link3 自碰撞，接触冲量范数和分别约11.993、9.085。瓶子场景还包含机器人与瓶子、桌面的接触。不是仅凭视频判断原因。

这里的旧 Full 是此前 SR25.43% 连续仿真版本保存的成功回合动作，仅比较前32条。没有把此重放称为原生 TOPP 全量验收，也不能推出所有 Full 回合都没有大接触误差。

## 相同 Full 动作的执行器消融

篮筐任务保留同一原始 Full 动作、初始状态和物理步长，只改变动作处理：

| 处理 | 最大跟踪误差 |
|---|---:|
| 原线性执行，正常碰撞 | 0.007313 rad |
| 相同原始端点，仅改 C2 插值，不投影，正常碰撞 | 0.006901 rad |
| 当前逐关节投影 + C2，正常碰撞 | 0.337568 rad |
| 当前逐关节投影 + C2，取消机器人碰撞 | 0.006930 rad |

投影后的最大端点改写为1.282488 rad；第19动作区间，左臂两个原目标为2.146636/1.510179 rad，投影后成为3.149281/2.752112 rad。误差峰值发生在3.460秒，此时 fl_link7 接触桌面。未投影 C2 仅作原因消融，不代表已经通过当前速度/加速度/jerk约束，不能直接替换生产执行器。

当前代码的因果逐关节裁切只保证各关节 q/v/a/jerk，不保证联合姿态/机器人路径无碰撞。段末速度被固定为端点割线速度，遇到目标减速/换向时，局部可行域可能要求继续向原方向前进。逐关节裁切随后改变多个关节的配合。该机制与本次观测一致；不能把本次所有闭环差异都唯一归因于它，慢参考陈旧/更新仍需后续对照。

当前零初始化残差只能保留“已经投影的慢路计划”，不是原 Full 动作。快路修正上限0.06 rad，无法修复1 rad量级的基线投影偏差。正式训练前需要先解决基线轨迹改写、协同运动及制动处理，继续保持严格物理区间和队列承诺。
